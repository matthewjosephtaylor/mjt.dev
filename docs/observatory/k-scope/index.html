K-Scope

The headline economy and the lived economy are diverging. Capital metrics — the S&P 500, corporate profits, top-percentile wealth — climb. Labor metrics — participation, hires, wages as a share of GDP — drift or decline. Both are true simultaneously. The K-shape is the structure underneath the aggregate.

This dashboard tracks that divergence using Federal Reserve data. Every chart shows the same economy from a different angle. The data updates monthly.
