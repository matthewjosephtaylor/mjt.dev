# mjt.dev

Personal website for Matthew Joseph Taylor. Static HTML + CSS served via GitHub Pages from the `docs/` directory. No build toolchain, no frameworks — hand-authored HTML with a shared `style.css` design system.

## Structure

```
docs/                    # GitHub Pages root (CNAME → mjt.dev)
├── index.html           # Landing page — hero + domain cards
├── style.css            # Design system (CSS custom properties, dark/light)
├── favicon.ico
├── CNAME                # GitHub Pages custom domain
├── fonts/               # Inter font files
├── assets/              # Profile image, shared assets
├── about/index.html     # About page
├── art/index.html       # Art gallery — lazy-loaded thumbnail grid
├── art-*/index.html     # 113 individual art pages (generated)
├── blog/                # Blog posts (legacy, cleaned up)
├── process/index.html   # Creative process page
└── thanks/index.html    # Acknowledgments
scripts/
└── build-art-pages.js   # Node.js — generates art-*/index.html from images (zero deps)
```

## Design System

`docs/style.css` — CSS custom properties with automatic dark/light mode:

- `--bg`, `--surface`, `--border`, `--text`, `--accent` — color tokens
- `--measure: 65ch` — prose line length
- `--font: Inter` — typography
- `.content`, `.hero`, `.gallery-grid`, `.art-viewer` — layout components
- `@media (prefers-color-scheme: light)` — automatic light mode override

## Art Gallery

113 pieces. Each art page is a standalone HTML file generated by `scripts/build-art-pages.js`:

```bash
node scripts/build-art-pages.js    # Regenerates all art-*/index.html
```

The gallery index (`docs/art/index.html`) uses lazy-loaded thumbnails with `loading="lazy"`.
